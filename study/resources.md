### 0.4 이번 업데이트의 핵심 반영 (2026-05-28 차수)

- `flame`은 `^1.18.0`이 아니라 **`^1.37.0`** 기준으로 수정했습니다.
- Flame 공식 패키지는 35종으로 고정하지 않고, pub.dev publisher 기준 **38종**으로 갱신했습니다.
- Nakama는 실시간 이동/전투 서버가 아니라 **메타 서버**로 확정했습니다.
- 게임 로직/이동/전투는 **자체 Go UDP Zone Server**에서 server authority로 처리하도록 Phase 5~6과 서버 부록을 보강했습니다.
- 2.5D 맵은 Tiled 레이어 계약, custom property, Y-sort slice, 그림자/조명/청크 스트리밍까지 포함하도록 Phase 3을 확장했습니다.
- 몬스터/캐릭터는 sprite naming SSOT, actor data, attack timeline, hit-stop, screen shake, afterimage, telegraph를 학습 항목으로 추가했습니다.

### 0.5 2026-05-28 2차 검증/추가 반영 (이번 차수에서 새로 보강)

영역별 30+개 페이지 광범위 재조사를 통해 다음을 새로 반영했습니다.

- **Flame API 마이그레이션**: `HasGameRef` → **`HasGameReference`** (deprecate는 **v1.28.0**, PR [#3559](https://github.com/flame-engine/flame/blob/main/packages/flame/CHANGELOG.md))로 Prereq/Phase 1 코드 예시 갱신. (이전 차수 로그의 "v1.33부터" 표기는 오류였습니다 — 2026-05-29 차수에서 정정. §0.7 참조.)
- **충돌 mixin 권장 위치**: `with HasCollisionDetection`을 `FlameGame`이 아닌 **`World`에 부여**하는 패턴을 Phase 2/Phase 3에 명시. 정적 객체 많을 땐 `HasQuadTreeCollisionDetection` 권장.
- **Camera 2.0 회전/줌**: `CameraComponent` 2.0 + `Viewfinder`의 `angle`/`zoom` 동시 적용 예제를 Phase 3에 추가 (Isometric 회전 시 footY 보정 주의 포함). 이 angle/zoom은 **Flame 1.x 표준 API**입니다(이전 차수의 "1.30+" 표기는 신기능처럼 읽혀 오해를 줄 수 있어 정정 — angle/zoom은 1.30보다 훨씬 이전부터 안정 API).
- **Tiled 에디터 1.12.2 (최신 패치, 2026-05-27경)**: 1.12.0(2026-03-13)의 신기능 — list-valued custom property, Oblique orientation, layer blending mode, capsule object, **per-object opacity**, Properties view 전면 재작성 — 을 Phase 3에 명시. 1.12.1(2026-03-25)의 Properties view 회귀와 list-typed 속성 후속 버그를 1.12.2에서 수정. (주의: layer parallax는 1.12 신기능이 아니라 Tiled 1.5부터 있던 기능. Dart `tiled` 0.11.1 / `flame_tiled` 3.1.1은 동일.)
- **Rive Data Binding (ViewModel)**: 기존 state machine input deprecated. Phase 4의 컷씬/스킬 FX는 ViewModel + Data Binding으로 마이그레이션 권장 명시.
- **Spine 4.3 + flame_spine 0.3.0+5**: `initSpineFlutter()` / `onDetach()` 라이프사이클을 Phase 4 부록에 명시.
- **Nakama 매칭/파티 기능 버전 매핑 (정정)**: `MatchmakerProcessor` 훅은 **v3.29.0(2025-07-29)**, Party Listing API + Party Label은 **v3.28.0(2025-07-14)** 추가 기능입니다. 이전 차수에서 이를 "3.39 신규"로 표기한 것은 오류 — 둘 다 2025-07 기능입니다(§0.7 참조). Nakama **3.39.0(2026-05-20)**의 실제 신규는 ① storage 객체를 재시도와 함께 업데이트하는 런타임 함수, ② Satori 클라이언트 구성 가능 재시도입니다. Go 런타임 의존성은 동일자 출시된 **nakama-common v1.46.0**(2026-05-20)을 사용합니다(3.39.0 릴리즈 노트 본문엔 호환 버전 명시가 누락되어 있으나, 3.37.0→v1.44.2 / 3.38.0→v1.45.0 패턴상 v1.46.0이 짝).
- **Nakama Dart SDK 1.3.0 정체 경고**: 약 11개월 전 게시. Nakama 3.39 신규 Dart 바인딩이 없을 가능성이 큼 → raw RPC/socket 우회.
- **Go 1.26 Green Tea GC**: 공식 [go1.26 릴리즈 노트](https://go.dev/doc/go1.26)의 정확한 표현은 "GC를 많이 쓰는 실세계 프로그램에서 **GC 오버헤드 10~40% 감소**"입니다(Intel Ice Lake/AMD Zen4 이상에서 벡터 명령으로 +~10%, cgo 호출 오버헤드 ~30% 감소). 이전 차수의 "pause 최대 40% 감소 / throughput 10~15% 향상"은 2차 출처(InfoWorld/byteiota 등) 정리이므로, **공식 표현인 'GC 오버헤드 10~40% 감소'로 통일**해 Phase 6/7·server-architecture에 반영. Green Tea는 1.25 experiment → 1.26 기본(opt-out은 1.27 제거 예정).
- **인프라 버전 명시**: PostgreSQL은 최신 메이저 **18.x(18.4, 2026-05-14)** 권장, 이전 메이저는 **17.x(17.10)**. ⚠️ PostgreSQL 본체에는 **LTS 개념이 없습니다** — 모든 메이저가 출시 후 5년 지원 정책을 동일하게 따릅니다(이전 차수의 "17 LTS" 표기는 오개념이라 정정. "LTS"는 Aurora/Cloud SQL 같은 클라우드 벤더 용어). Nakama Docker 기본 12.2-alpine은 EOL이므로 18로 override. Redis **8.6.3**(2026-05-05), protoc **v35.0**(2026-05-19), Go `google.golang.org/protobuf v1.36.11`(2025-12-12, APIv2), `quic-go v0.59.1`(2026-05-11), `kcp-go v5.6.64`(2026-01-26). (protoc는 v35.x, Go protobuf 런타임은 v1.36.x로 버전 체계가 다르며 약 5개월 릴리즈 간극은 정상.)
- **트랜스포트 매트릭스(2026)**: 실시간 PvP=KCP Turbo, 로비/매칭=QUIC, 콘솔=ENet/Steam Sockets, 웹=WebTransport 또는 flutter_webrtc 1.4.1 DataChannel을 Phase 5에 의사결정 표로 추가.
- **WebTransport 2026-03 Baseline 진입**: Safari 26.4(2026-03-24)가 WebTransport를 기본 탑재하며 Chromium/Edge/Firefox와 함께 마지막 공백을 해소. 단 [caniuse](https://caniuse.com/webtransport)는 구버전 Safari·레거시 브라우저 미지원을 이유로 "완전 Baseline은 아님"이라는 보수적 견해도 병기 → 운영에서는 WebTransport(HTTP/3 datagram) 우선 + `flutter_webrtc` DataChannel(`ordered:false`, `maxRetransmits:0`) **fallback 이중화**를 권장. Flutter 이슈 [#154465](https://github.com/flutter/flutter/issues/154465)는 현재 **Closed** 상태이나(이전 차수의 "이슈가 열려 있어 통합 미완"은 정정), Dart/Flutter 공식 WebTransport 바인딩 패키지는 **여전히 부재**하여 `dart:js_interop` 직접 바인딩이 필요하다는 결론은 유효.
- **2024~2026 네트코드 신표준**: SnapNet(UE5 SDK) input-delay vs rollback 결정 트리, Valorant 128-tick + 0.5/1프레임 버퍼 + backwards reconciliation 사례, Glenn Fiedler의 새 도메인 mas-bandwidth.com + `netcode` 보안 핸드셰이크 레퍼런스를 Phase 5 학습 자료에 추가.
- **AoI 2025~2026 표준**: uniform grid + 9-cell이 모바일 MMO 기본, 동적/희소 월드는 non-blocking concurrent quadtree(Quadboost). Phase 6 §4에 반영.
- **안티치트 3중 레이어(2025 표준)**: Google Play Integrity API + Apple App Attest(platform attestation) + 서버측 ML 행동분석 + Server Authority. Phase 8 §7.1에 보강. Bungie Marathon 사례 인용.
- **공식 패키지 dormant 경고 명확화**: `flame_jenny`(2023-01-14, 약 3년 미업데이트). ⚠️ 근거 정정 — `flame ^1.6.0`은 caret 범위상 `>=1.6.0 <2.0.0`이라 1.37.0을 **포함**하므로 `pub get` 자체는 통과할 수 있습니다. 실제 비호환은 버전 제약이 아니라 1.28(HasGameRef deprecate)/1.29(children retain parent)/1.30 등 다수 breaking change로 인한 **컴파일·런타임 깨짐** 때문입니다(미도입 결론은 유지). 대신 본체 `jenny` 1.5.1(Flame 비의존)을 직접 사용 권장. `flame_shells`(2020-03-19, 약 6년, `flame ^0.18.1`로 사실상 사용 불가), `oxygen`(2024-03-19, 약 2년 dormant). flame-official-packages.md §0.2에 상태 컬럼 추가.

## 9. 빠른 시작 명령어 모음

```bash
# Flutter / Flame
flutter create my_game
cd my_game && flutter pub add flame:^1.37.0 flame_tiled:^3.1.1 flame_audio:^2.12.1
flutter pub add nakama:^1.3.0 web_socket_channel:^3.0.3 protobuf:^6.0.0
flutter pub add freezed_annotation json_annotation flutter_riverpod:^3.3.1
flutter pub add flutter_webrtc:^1.4.1   # (선택) 웹 클라용 unordered DataChannel
flutter pub add --dev build_runner freezed:^3.2.5 json_serializable:^6.14.0 flame_test:^2.2.4
flutter run -d chrome    # 빠른 테스트
flutter run -d ios       # 실기기
flutter run --profile    # 성능 측정

# Nakama (Docker — PostgreSQL은 최신 메이저 18로 override 권장. LTS 개념 없음 / 5년 지원)
git clone https://github.com/heroiclabs/nakama-project-template
cd nakama-project-template
# docker-compose.override.yml 등에서 postgres:12.2-alpine → postgres:18 로 수정
docker compose up

# Go 서버 (예시 — Go 1.26.3 권장, Green Tea GC는 1.26부터 기본 활성화)
go mod init game/zone
go get github.com/heroiclabs/nakama-common@v1.46.0   # Nakama 3.39.0(2026-05-20)의 짝 nakama-common
go get github.com/quic-go/quic-go@v0.59.1            # 로비/매칭용 QUIC
go get github.com/xtaci/kcp-go@v5.6.64               # 실시간 PvP용 KCP (ENet 대비 실측 약 3~3.4배 우수)
go get google.golang.org/protobuf@v1.36.11           # APIv2. protoc는 v35.0과 정합. protoc-gen-go도 v1.36.x
go run ./cmd/zone
go tool pprof http://localhost:6060/debug/pprof/profile
# goroutineleak 프로파일은 Go 1.26 실험 기능 — 빌드 시 GOEXPERIMENT 활성화 필요
GOEXPERIMENT=goroutineleakprofile go build ./cmd/zone
go tool pprof http://localhost:6060/debug/pprof/goroutineleak   # net/http/pprof 엔드포인트

# 부하 테스트 봇
go run ./cmd/bot -n 100 -server localhost:9000
```
